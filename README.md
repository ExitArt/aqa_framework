Экосистема автоматизации UI-тестирования (E-Commerce Web Application)

Проект представляет собой комплексный фреймворк автоматизации тестирования для [saucedemo.com]. Фреймворк построен с соблюдением лучших практик разработки (ООП, SOLID) и паттернов проектирования.

## 🛠️ Стек технологий
* **Core:** Java 21
* **Web Driver:** Selenium WebDriver (с управлением через WebDriverManager)
* **Test Runner:** JUnit5 (управление потоками, группами и параметризацией)
* **Design Pattern:** Page Object Model (POM)
* **Build Tool:** Maven
* **Reporting:** Allure Report + Тестовые логи
* **CI/CD:** GitHub Actions

---

## 🏗️ Архитектура проекта (POM)
Код разделен на логические слои для обеспечения высокой поддерживаемости:
* `src/main/java/pages/` — Описание страниц, локаторов элементов и методов взаимодействия с ними.
* `src/main/java/utils/` — Хелперы для работы с конфигурациями, логированием и кастомными ожиданиями (Explicit Waits).
* `src/test/java/tests/` — Чистые тестовые сценарии, содержащие только бизнес-логику и проверки (Assertions).

---

## 📈 Покрытый функционал (Тест-кейсы)
1. **Авторизация:** Успешный вход, обработка невалидных данных (Data-Driven тесты).
2. **Корзина:** Добавление товаров из каталога, проверка динамического пересчета стоимости, удаление товаров.
3. **Оформление заказа (E2E):** Сквозной сценарий от выбора товара до финальной формы успешной оплаты.

---

## ⚙️ Локальный запуск
Для запуска тестов на вашем компьютере должны быть установлены **Java 17+** и **Maven**.

Выполните команду в терминале:
```bash
mvn clean test -Dsuite=smoke
```

---

## 📊 Отчетность и CI/CD

### Интеграция с GitHub Actions
Тесты автоматически запускаются в облаке при каждом `git push` в ветку `main`. Конфигурация описана в `.github/workflows/maven.yml`.
